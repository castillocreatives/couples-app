# Couples Barometer

A tiny app for two partners to stay in sync about how much they have to give each day.

- Each partner rates their daily capacity 1–10 every morning — and the app translates the number into guidance ('handle with care'), not just a score.
- Private-by-default friction capture — log the small irritations the moment they happen instead of letting them stack up.
- Therapist-style 'dig in' prompts that turn a low score into a real conversation.
- A weekly calibration scorecard both partners must finish to unlock each other's — so nobody reads a report their partner hasn't seen.

Built with React + TypeScript (client) and a TypeScript server with Drizzle/SQLite.
