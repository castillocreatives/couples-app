# Couples App (prototype)

A prototype app for couples communication: a daily 1–10 capacity check-in that
translates into guidance ("handle with care"), private-by-default friction
capture, therapist-style "dig in" prompts for stalled moments, and a weekly
calibration scorecard both partners complete before unlocking each other's.

Built with React + TypeScript (client) and a TypeScript server with Drizzle/SQLite.
